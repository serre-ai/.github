# Contributing to Serre AI projects

Thank you for helping. Each repository's own `CONTRIBUTING.md` takes precedence over
this file; read it first, because the tooling differs between projects.

## Before you start

- **Bugs:** open an issue with what you ran, what you expected and what happened.
- **Changes:** for anything beyond a small fix, open an issue first so the work can be
  agreed before you spend time on it. Most projects plan in their repository, so check
  whether an item already covers it.
- **Security issues:** never in public; follow the [security policy](SECURITY.md).

## Pull requests

- One change per pull request, with a description of the problem, the approach, and
  what a reviewer should look at sceptically.
- Commit messages and pull request titles follow
  [Conventional Commits](https://www.conventionalcommits.org/).
- The project's checks pass before review. A bug fix comes with the test that would
  have caught it.

## Licence of contributions

Unless you state otherwise, a contribution you submit is licensed under the licence of
the repository you submit it to. There is no separate contributor agreement, and you
keep the copyright in your work.

## Conduct

Everyone taking part follows the [Code of Conduct](CODE_OF_CONDUCT.md).
