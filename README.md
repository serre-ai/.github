# serre-ai/.github

The organisation profile shown on [github.com/serre-ai](https://github.com/serre-ai)
(`profile/README.md`), and the default community health files for every Serre AI
repository that does not have its own: [`SECURITY.md`](SECURITY.md),
[`CODE_OF_CONDUCT.md`](CODE_OF_CONDUCT.md), [`CONTRIBUTING.md`](CONTRIBUTING.md) and
[`SUPPORT.md`](SUPPORT.md).

A repository overrides a file by adding its own. Keep this repository's files general;
anything specific to one project belongs in that project.
