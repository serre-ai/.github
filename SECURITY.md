# Security policy

## Reporting a vulnerability

Report privately through the affected repository's **Security** tab, then **Report a
vulnerability** (GitHub Security Advisories). Do not open a public issue. If you cannot
use GitHub, email contact@serre.ai with "security" in the subject.

## What to expect

- Acknowledgement within 3 days.
- An assessment and a planned fix date within 14 days.
- A fix released as soon as it is ready, and credit in the advisory unless you prefer
  otherwise.

## Supported versions

Unless a repository's own policy says otherwise, only the latest release and the latest
commit on `main` receive fixes.
